KIAMBATI BIOGAS SOLUTIONS — WEBSITE
====================================

FILES INCLUDED
--------------
1. index.html   → The main website (all sections in one page)
2. styles.css   → All the styling / colors / layout
3. script.js    → All interactivity (menu, calculator, WhatsApp form, animations)


STEP 1 — COPY THE FILES TO YOUR COMPUTER
----------------------------------------
1. Open the folder where you downloaded the files.
2. Create a new folder on your Desktop called "kiambati-biogas"
3. Copy index.html, styles.css and script.js INTO that folder.
   (All 3 files must sit in the SAME folder — do NOT put them in subfolders.)


STEP 2 — OPEN IN VS CODE (Windows)
----------------------------------
1. Download & install Visual Studio Code: https://code.visualstudio.com
2. Open VS Code → File → Open Folder...
3. Select your "kiambati-biogas" folder → click "Select Folder"
4. You will see all 3 files in the left sidebar (Explorer).
   Click any file to edit it.

RECOMMENDED VS CODE EXTENSIONS (for easier editing):
- "Live Server" by Ritwick Dey  → lets you see changes instantly
- "Prettier"                    → formats your code nicely


STEP 3 — VIEW THE WEBSITE LOCALLY
---------------------------------
EASIEST WAY (with Live Server extension):
1. In VS Code, right-click index.html
2. Click "Open with Live Server"
3. The site opens in your browser and auto-refreshes when you edit.

WITHOUT EXTENSIONS:
1. Open File Explorer, go to your folder
2. Double-click index.html → it opens in your browser.


STEP 4 — EDIT KEY INFO
----------------------
- Change the phone number: open script.js and index.html, search (Ctrl+F)
  for "254723051086" and replace with the new number (keep no + or spaces).
- Change prices: open script.js, look for the PRICES section near the bottom.
- Change text: open index.html and edit the words between the tags.


STEP 5 — PUT IT ONLINE (FREE) — so clients can find it
------------------------------------------------------
OPTION A — Netlify Drop (easiest, free):
1. Go to https://app.netlify.com/drop
2. Drag your whole "kiambati-biogas" folder into the page
3. You instantly get a live link like https://kiambati-biogas.netlify.app
4. Buy a domain (e.g. kiambatibiogas.co.ke ~ KSh 1,000/yr) and connect it
   in Netlify → Domain settings.

OPTION B — GitHub Pages (free):
1. Create a free account at github.com
2. Click "New repository" → name it kiambati-biogas → Public
3. Upload the 3 files → Settings → Pages → Source: main branch
4. Your site goes live at https://YOURUSERNAME.github.io/kiambati-biogas/

OPTION C — Buy hosting in Kenya (for .co.ke domain):
Providers like Truehost / Kenya Web Experts / HostPinnacle (~KSh 2,000–5,000/yr),
then upload the files via their cPanel File Manager.
